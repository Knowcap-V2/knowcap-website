# Content and Features — Inbox

Drop zone for Hassan's raw inputs (YouTube links, one-liner ideas, transcripts).
Claude lightly synthesizes each one and files it here for Hassan to review later.

## Layout
- `youtube/` — one file per video. Filename = slugified title. Body = link + 3-5 bullet synthesis + raw transcript (if provided).
- `ideas/` — one-sentence ideas, grouped by theme file.
- `transcripts/` — longer pasted transcripts that aren't tied to a YouTube link.
- `INDEX.md` — running table of contents, newest first.

## Synthesis rules
- Stay light: 3-5 bullets max per item, no editorializing.
- Preserve the raw input verbatim below the synthesis.
- If a video/idea maps to a known Knowcap/SMEtools/Ariika initiative, add a one-line "Relates to:" pointer — don't expand.
- Date every entry (YYYY-MM-DD).
