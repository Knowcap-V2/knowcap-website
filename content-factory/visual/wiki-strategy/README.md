## How to use

- Each entry has a one-line **TL;DR** + structured key points so any agent can extract content briefs, feature PRDs, or talking points without re-reading the source.
- Cross-link rather than duplicate. Use full-path wikilinks `[[wiki/Knowcap/content-and-features/X]]`.
- Raw sources live in `~/Github/knowledge/llm-wiki/raw/` (`raw/bookmarks/youtube/` for video notes, `raw/research/` for voice memos).
- Superseded files stay in place with a frontmatter `status: SUPERSEDED` and a link forward. Never delete original captures — they're history.
