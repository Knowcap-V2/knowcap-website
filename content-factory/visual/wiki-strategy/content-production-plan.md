# Knowcap content production plan

> Hassan's words in the 100% memo: *"This is a complete content creation strategy."* This file extracts the **content pieces** explicitly named (or strongly implied) in the two 2026-05-07 voice memos. Each row is a piece to produce. Status field tracks where each piece stands.

## A. The 5×3 master grid (Hassan's explicit plan — 15 minimum pieces)

Every Knowcap memory category, at each autonomy level, is one content piece. Use the canonical 9-edge taxonomy from [[wiki/Knowcap/content-and-features/typed-edge-knowledge-graph]] when describing what the agent does.

| Category | L1 — Notify | L2 — Research + propose | L3 — Mitigate autonomously |
|---|---|---|---|
| **Risk** | Supplier PO-delay flagged mid-meeting → routed to owner before call ends *(scripted scenario in memo)* | Spin research agent → mitigation drafted as PDF/video/Telegram → Hassan approves → sent to team | ERP module built on the spot, OR contacts 5 alt suppliers on WhatsApp to check capacity |
| **Decision** | Decision auto-tagged + sent to involved parties | Research-agent proposes SOP for similar decisions, attached for approval | Decision tree auto-generates SOPs; pushes to all involved employees |
| **Task** | Task auto-assigned post-meeting from extraction | Research-agent drafts a how-to + delivers in chosen format | **AI does the task** — Claude Code ships a feature, sends staging link, asks for merge |
| **Topic** | Notable topic surfaced to owner | Research-agent assembles deep-dive (NotebookLM podcast/deck) | Shopify–Odoo reel → Higgsfield → Buffer → Instagram, post w/ or w/o approval |
| **Party** | Mention count surfaced ("Sarah referenced in 12 meetings this month") | Sentiment summary drafted per party + delivered | Customer-sentiment-triggered action (e.g. apology email + recovery offer) |

15 pieces minimum. Each grounded in real material from Hassan's 3 companies (one in 6 countries, 300+ people = use-case factory).
