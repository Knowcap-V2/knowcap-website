# Content Pipeline

Blog drafts before they ship.

| Folder | What |
|---|---|
| `strategy/` | Content strategy + marketing content plan |
| `drafts/` | In-progress posts |
| `ideas/` | Concepts pre-draft |
| `video/` | Video briefs (demo, animated) |

When a draft is approved, move it to `app/content/blog/<slug>.md` so the Next.js site renders it.
